# Asme — Landing Page

A minimal luxury landing page recreation built with **React**, **TypeScript**, **Vite**, **Tailwind CSS**, **Framer Motion**, and **Lucide React**.

## Features

- **Liquid Glass Aesthetic**: Translucent glass pills and cards using backdrop blur, inner specular highlights, and multi-stop border gradients.
- **Instrument Serif Typography**: Elegant serif display headers loaded via Google Fonts.
- **Hero Video Background**: Seamless vanilla JS requestAnimationFrame crossfade loop with full-viewport coverage.
- **Scroll-triggered Animations**: Framer Motion `useInView` staggered transitions.
- **Sections**:
  - Hero with Navigation & Newsletter Email Input
  - About Section
  - Featured Video Showcase with interactive Approach card
  - Philosophy (*Innovation x Vision*) with 2-column media & text
  - Services (*What We Do*) with interactive video preview cards

## Tech Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
